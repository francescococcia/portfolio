# Product

## Register

brand

## Platform

web

## Users

Recruiters and hiring managers for cyber security roles (analyst, penetration tester, security engineer), scanning quickly between other candidates — often from a LinkedIn or CV link, on desktop at work. Secondary: security professionals and hackathon peers checking Francesco out before collaborating.

## Product Purpose

Francesco Coccia's personal portfolio — the single place that shows what he has actually built and done in security. It deliberately replaces a downloadable CV: the site itself is the CV. Success is a recruiter moving him forward in a hiring process because the portfolio made his ability concrete.

## Positioning

The attacker who ships: four years of enterprise production engineering plus offensive security practice. "I think like an attacker and build like an engineer."

## Conversion & proof

- Primary CTA: Get in touch (email). Secondary: GitHub / LinkedIn profiles.
- The line a visitor remembers after 10 seconds: "Thinks like an attacker, builds like an engineer."
- Belief ladder: (1) this is a real security professional, not a template with a résumé → (2) he has shipped production software at enterprise scale → (3) he actively practices offensive security, not just theory → (4) contacting him is easy and worth it.
- Proof on hand: quantified experience bullets (~90% SQL-injection surface reduction across 12 modules, 3 major releases serving 500+ clients), NCSC-certified MSc at Greenwich, AZ-900, active TryHackMe/HackTheBox profiles, and the public site repo itself (github.com/francescococcia/portfolio).

## Brand Personality

Precise, calm, credible. Quiet confidence: the voice states facts with numbers and lets them land; no hype words, no fear-mongering, no hacker theatrics. Reference: ajanshul.vercel.app — specifically its card-to-modal case studies and restrained editorial calm, not its stack.

## Anti-references

Hacker-costume portfolios: neon-green-on-black terminal theater, glitch effects, particle networks, matrix rain, dossier stamps. (Three themed directions were explicitly rejected in Aug 2026 — see git history for the old design.) Also: generic AI landing-page grammar — identical card grids, section eyebrows, gradient text.

## Design Principles

- Proof over claims: every assertion carries a number, artifact, or link a recruiter can check.
- Quiet surface, sharp content: the design stays restrained so the work reads loud; boldness is spent on typography and one green accent, nowhere else.
- The site is the credential: lean, fast, no trackers, security-conscious build — the implementation itself demonstrates engineering judgment.
- One takeaway per section, all roads lead to contact.
- Show, don't describe: design changes are proposed as complete clickable mockups before touching production.

## Accessibility & Inclusion

WCAG AA: ≥4.5:1 body contrast in both themes, full keyboard navigability (including the project modals), visible focus states, and the global prefers-reduced-motion fallback already in global.css.
